# Java AI Agent 工程化项目
## 🔹 项目定位
对标**AI应用研发工程师**岗位要求，独立开发的生产级Java AI Agent，实现多工具自主调用、RAG知识库、流式输出、上下文记忆全功能闭环。

## 🔹 核心技术栈
- 框架：SpringBoot + LangChain4j 0.34.0（Java版LangChain生态）
- 大模型：Ollama + qwen3:8b（本地私有化部署，无API依赖）
- 核心能力：AI Agent 工具函数调用 + RAG向量检索 + 流式输出 + 会话级记忆管理
- 工程化：LLM幻觉防控、Prompt注入防护、任务自动拆解

## 🔹 核心功能（100%匹配岗位JD）
1.  **多工具自主决策**：规范检查/性能分析/单元测试生成，Agent根据需求自动选择工具
2.  **生产级RAG系统**：文档分块、向量入库、检索阈值过滤，解决大模型幻觉问题
3.  **AI Infra优化**：流式输出，降低用户等待延迟，符合企业级AI应用标准
4.  **上下文记忆管理**：会话级记忆仓库，同一会话永久记住上下文，多用户互不干扰
5.  **Prompt工程**：防注入、确定性兜底、主动任务拆解，生产级Prompt调优

## 🔹 项目亮点
- 纯Java工程化实现，完全符合企业研发规范
- 本地大模型落地，数据安全可控
- 完整AI应用闭环，可直接演示、可扩展
- 精准对标AI应用研发工程师岗位核心要求

## 🔹 运行方式
1.  启动Ollama服务，拉取qwen3:8b模型
2.  启动SpringBoot项目
3.  调用接口体验AI Agent全功能
